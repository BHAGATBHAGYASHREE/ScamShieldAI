Engineering Defense

Why Hybrid Beats Heavy LLMs.

Why we chose 18 cyber threat heuristics + TF-IDF instead of a 100M parameter BERT.

🐢 Heavy LLM (BERT / DeBERTa)

  • ⏱️ 300 ms latency per message
  • 💸 Requires costly dedicated cloud GPUs
  • ❓ Opaque black box (no token-level explainability)
  • 🔒 Privacy risk sending private SMS to third-party APIs

⚡ ScamShield Hybrid Architecture

  • 🚀 0.08 ms inference speed on standard CPU
  • 💰 $0 GPU overhead (runs on free-tier containers)
  • 🔍 100% token-level heuristic explainability
  • 🏆 95.1% Accuracy • 91.96% Precision • 0.9858 ROC-AUC
Speaker Script (3:45 – 4:45) "Why didn't we just use BERT? Because in mobile security, latency and cost kill user adoption. BERT takes 300ms and requires an expensive GPU server. Our hybrid pipeline combines 18 domain heuristics—Shannon entropy, URL shorteners, currency syntax, callback telephone patterns—fused with pruned n-grams. The result is 95.1% accuracy, 91.9% precision, and a blistering 0.08 millisecond inference speed on a standard CPU."
