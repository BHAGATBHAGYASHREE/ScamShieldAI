💬 The Anatomy of the Trap: Scammer fabricates ₹3,000 transfer → Creates urgency ("Please return mam 2000") → Sends their own QR to siphon real victim funds.

🎭 The Psychological Weapon

The scammer never sent ₹3,000. They weaponized false guilt and urgency. In the confusion, victims panic and return ₹2,000 of their own money without checking their bank account.

🚫 Why Standard Filters Fail

Traditional spam filters look for marketing keywords. This attack used conversational language and images inside WhatsApp. We need intelligent communication analysis before money moves.

Engineering Defense

Why This & Better Than The Alternative?

Every design decision was deliberate — balancing consumer real-time constraints against academic complexity.

Component Our Choice Obvious Alternative Why Ours Wins
Architecture Hybrid TF-IDF + 18 Cyber Heuristics Heavy LLM (BERT/DeBERTa) 0.08ms CPU latency vs 300ms GPU latency. Zero GPU cloud costs.
Preprocessing Standalone features.py Inline Notebook Transformer Prevents fatal __main__ joblib serialization bug in production.

Production Infrastructure

Enterprise-Grade MLOps Delivery.

From raw data versioning to automated cloud deployment.

📦 DVC Pipeline Reproducibility

Multi-stage DAG (prepare_data → train_and_evaluate) tracking 36,261 messages across 4 raw datasets. Guaranteed zero train-test leakage.

⚡ Automated CI/CD & Docker Hub

GitHub Actions triggers on every git push: runs 13 unit tests, builds a multi-stage Docker container, and auto-pushes to Docker Hub (bhagyashreebhagat/scamshield-ai:latest).

☁️ Cloud Deployment

Render Blueprint (render.yaml) and AWS EC2 user-data script for 1-click cloud launch. Accessible publicly via encrypted live URL.

🛡️ Robustness & Safety

13 automated unit & integration tests covering edge cases (empty strings, extreme entropy, URL parsing, Pydantic validation errors).
